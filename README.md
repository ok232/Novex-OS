# 🚀 NovexOS

**A modern Linux-based operating system built for everyone.**

NovexOS is an independent operating system by **Novex Technologies**, designed to provide a modern and user-friendly Linux experience.

### ✨ Features

- Modern desktop experience
- Custom themes and icons
- Novex Store for applications
- Multiple user accounts
- Future business tools

### 📦 NIA (Novex Installable Application)

NIA is NovexOS's planned custom application package format. `.NIA` files are designed to make installing and distributing applications simple, with a consistent installation experience across compatible Linux distributions.

### 💻 Compatibility

NovexOS is designed to support Linux-compatible hardware that can boot `.img` disk images, including:

- Raspberry Pi devices
- ARM64 systems
- x86-64 computers
- Compatible laptops and desktops

Actual compatibility depends on hardware drivers and image support.
